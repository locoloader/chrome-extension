# Locoloader Chrome Extension

### 🛠️ Installation
1. Click [here](https://github.com/locoloader/chrome-extension/archive/refs/heads/main.zip) to download the Locoloader extension from GitHub.
2. Extract (unzip) the downloaded file. This creates a folder named `chrome-extension-main`. Do not delete or move this folder after installation, because the extension runs directly from it.
3. Open the address `chrome://extensions` in your Chrome browser and turn on the `Developer mode` toggle in the top-right corner.
4. Drag and drop the `chrome-extension-main` folder anywhere onto the extensions page to install it. Note that Windows sometimes nests the folder like this: `chrome-extension-main\chrome-extension-main`. If this happens, drag and drop only the inner folder into Chrome. If you use the outer folder, the installation will fail.

### 💡 Installation Tips
- If you prefer not to install the extension from the source code, you can still use our [Firefox extension](https://addons.mozilla.org/en-US/firefox/addon/locoloader/).
- Before dragging and dropping the extension folder into Chrome, move it out of your `Downloads` folder. This ensures you won't accidentally delete it later when clearing out other downloaded files.

### ⚙️ Settings
1. Open the address `chrome://extensions` in your Chrome browser.
2. Find the Locoloader extension and click the `Details` button.
3. If you use Incognito Windows, turn on the `Allow in Incognito` toggle.
4. Make sure the `Site access` option is set to `On all sites`.
5. Make sure the `Allow access to file URLs` toggle is turned on.

### ⬆️ Update
1. Open the address `chrome://extensions` in your Chrome browser.
2. Remove the current Locoloader extension.
3. Follow the [installation steps](#installation).

### 🤔 Why isn't this in the Chrome Web Store?
This extension was available in the Chrome Web Store for nearly 4 years and was installed by more than 100k users. Unfortunately, it was removed from the store due to its potential use with adult content.
